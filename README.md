# Zaza International — лендинг

Одностраничный сайт команды разработчиков Zaza International: https://zazainternational.ru

Статика без сборки: `index.html` + `logo.jpg`. На сервере лежит в `/opt/zaza-site`,
раздаётся Caddy (Let's Encrypt выпускается автоматически).

Дизайн — редакционный минимализм: чёрный hero, бумажные секции, один акцентный
цвет. Без градиентов, теней и эмодзи.
